## 📝 Notes
-----------------------------------------

1. All pricing is currently in INR (₹)
2. Distance calculations use Haversine formula (straight-line)
3. Route Matrix API provides actual road distance
4. Multi-modal routes (car→train, bus→train) are generated algorithmically
5. Transfer times are estimated (30min for car→train, 20min for bus→train)
